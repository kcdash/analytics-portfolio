The data: Maple & Main

Every project runs on the same fictional company: Maple & Main, a Canadian omnichannel retailer with a loyalty program. The data is generated by code in this repository, so anyone can reproduce it.

It behaves like real retail data. Customers churn for reasons a model can find, campaigns have holdout groups, media has diminishing returns, and the raw tables carry the duplicates, format breaks and outliers that real data always has.
